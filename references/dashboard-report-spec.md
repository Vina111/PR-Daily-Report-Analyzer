## 1. 默认导航

中文界面默认使用六个视图：

1. `每日简报`
2. `行业情报`
3. `客户与竞品`
4. `媒体机会`
5. `风险监测`
6. `设置`

仅在用户明确要求时加入语言切换。不要为了保留旧原型而自动增加英文 UI。

## 2. 首页 KPI

首页数字只保留原生报道口径（用户固定规则：通稿与转载不进入输出）：

| 指标 | 口径 |
|---|---|
| 新增事件 | 聚类后的独立事件 |
| 原生报道 | 第三方独立采写内容（仅外媒/海外版） |
| 行业 Tier 1 | 行业 Tier 1 的原生报道 |
| 重点风险 | Red 与 Orange 事件 |
| PR 机会 | 有明确证据和动作的机会 |

通稿与转载只在后台计数，数据口径处以一句话说明“本期检测到 N 篇通稿、M 个转载页面，已按规则排除”。

示例：

```text
6 篇第三方原生报道｜1 篇深度采访｜3 家行业 Tier 1 媒体
```

禁止写成：

```text
获得 208 篇媒体报道
```

## 3. 事件卡片

每个重点事件显示：

```text
中文标题
原文标题
地区标签（强制，如 美国 / 欧洲 / 日韩 / 全球多地区）
媒体 / 记者 / 时间
内容类型标签（仅原生报道类型）
媒体 Tier
涉及行业、公司、产品
2–3 句中文摘要
为什么重要
建议行动（最多一句话；仅客户相关 / Red/Orange 风险 / Pitch 机会）
风险或机会等级
置信度
原文链接
同事件的原生报道数量
```

同一事件的不同媒体角度放在可展开区域，不能用一张卡片重复铺满页面。

## 4. 单行业与多行业布局

### 单行业

首页顺序：

1. Executive Summary；
2. Must-read Events；
3. 客户与竞品；
4. 媒体与记者趋势；
5. 风险与机会；
6. 建议行动。

### 多行业

广度优先（用户固定规则）：每个行业默认只保留 2–3 条最高优先级事件，覆盖所有监测行业优先于单行业深度；总条数控制在用户要求范围内。单个行业的事件数不得超过其他行业 2 倍以上，除非该行业出现 Red 级风险。

先建立跨行业概览：

| 行业 | 独立事件 | 原生报道 | 行业 Tier 1 | 风险 | PR 机会 |
|---|---:|---:|---:|---:|---:|

再为每个行业提供独立分区，每条事件带地区标签。支持按：

- 行业；
- 公司；
- 地区；
- 时间；
- 内容类型；
- 媒体 Tier；
- 风险等级；
- 机会类型；

筛选。

跨行业共同趋势必须引用至少两个行业的具体事件作为证据。否则标记为“单行业信号”。

## 5. 媒体机会

每个机会卡片显示（精简版）：

```text
机会主题
近期媒体信号
相关媒体与记者
建议 Pitch 角度（一句话）
建议时间窗口
```

Deals/Affiliate 只在消费品、大促或用户明确选择时启用。B2B、医疗、工业或企业科技项目不要默认展示 Deals 模块。

## 6. 风险监测

按 `Red / Orange / Yellow` 分组。每条风险必须说明：

- 来源类型：官方、原生报道、通稿、公司自述或市场信号；
- 已确认事实；
- 尚未确认的部分；
- 传播范围和增长；
- 受影响的客户、公司、产品或行业；
- 建议回应、准备或观察；
- 下一次检查时间。

正式报告中没有风险时显示“本期未发现达到预警阈值的事件”，不要制造示例风险。

## 8. Markdown 日报

```markdown

监测范围：
监测时段：
数据来源：仅限外媒及国内头部媒体海外版的原生报道（通稿已强制剔除）

## 今日结论

1. ...
2. ...
3. ...

## 行业关键事件

### 事件名称｜地区标签（如：美国）
- 发生了什么：
- 为什么重要：
- 建议行动（一句话，仅客户相关/风险/机会）：
- 来源：

## 客户与竞品

## 媒体与记者趋势（仅原生报道）

## 风险监测

## Pitch 机会（精简版）

## 数据口径
```

日报按行业分区时每行业 2–3 条封顶，每条必须带地区标签。

日报正文以中文为主，媒体、记者、品牌、产品和原文标题保留原语言。

## 9. 交付前检查

- 所有链接可打开或明确标记不可访问；
- 所有日期位于用户要求的时间窗口；
- 每条新闻都有地区标签；
- 所有来源均为外媒或国内头部媒体海外版，无国内版媒体混入；
- 输出中无通稿、转载稿、疑似转载或公司自有内容；
- 原生报道按事件聚类，同一事件没有重复计数；
- 多行业项目各行业条数均衡（默认每行业 2–3 条）；
- 建议行动均为一句话以内，且只出现在客户相关/风险/机会条目；
- 媒体 Tier 符合行业语境；
- 新闻摘要与原文事实一致；
- 风险等级与来源可信度匹配；
- 多行业比较披露了搜索范围和预算；
- 页面无默认英文导航；
- 没有未标注的模拟数据；
- 没有暴露 API Key、Webhook 或私有配置。
